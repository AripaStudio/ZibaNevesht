# زیبا نوشت

**زیبا نوشت** یک نرم‌افزار کوچک و سرگرمی‌محور است که با هدف بازی با واژه‌ها و شعر پارسی ساخته شده است.

این پروژه در آغاز بسیار ساده بود؛ برنامه‌ای کوچک با یک دکمه که نوشتهٔ واردشده را می‌گرفت و آن را به شعری از خیام تبدیل می‌کرد. اما به‌مرور گسترش یافت و اکنون از چند شاعر، چند ابزار نوشتاری و امکانات دیگری پشتیبانی می‌کند.

> این نرم‌افزار بیشتر برای سرگرمی و تجربه ساخته شده است و همچنان جای کار و گسترش دارد.

## امکانات

- نمایش و انتخاب شعر از شاعران:
  - خیام
  - رودکی
  - حافظ
  - باباطاهر
  - سعدی
- دریافت نوشته و نمایش شعر مرتبط با آن.
- **مِشمره** برای شمردن واژه‌های نوشته و نگه‌داری واژه‌های پرکاربرد.
- نگه‌داری ۱۰ واژهٔ برتر در مِشمره.
- **گوش‌به‌زنگ** برای زیر نظر گرفتن واژه‌های دلخواه.
- سه ردهٔ هشدار در گوش‌به‌زنگ:
  - هشدار سپید
  - هشدار نارنجی
  - هشدار سرخ
- پوستهٔ روشن و تیره.
- پشتیبانی از دبیرهٔ **پارسی-آریپا**.
- استفاده از فونت **ParsiAripa** در کنار فونت فارسی موجود در نرم‌افزار.

## پارسی-آریپا

زیبا نوشت از **پارسی-آریپا** نیز پشتیبانی می‌کند و فونت آن را همراه خود دارد.

پارسی-آریپا یک دبیرهٔ نوین بر پایهٔ اوستای کهن و اوستای نوین است که برای نوشتن پارسی امروز ساخته شده است.

برای آشنایی بیشتر با پارسی-آریپا می‌توانید جستار آن را بخوانید.

## دریافت نرم‌افزار

برای دریافت نسخه‌های منتشرشدهٔ زیبا نوشت به بخش **Releases** ریپوزیتوری مراجعه کنید.
